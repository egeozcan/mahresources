# Shortcode ideas

These shortcodes were planned on 2026-11-24 in a round of 15 ideas. Each plan went through a plan → independent evaluation → revise loop. An evaluator scored every version on consistency with the codebase and on usefulness to template authors. The first five plans to average 8.5 or more were implemented: `[calc]`, `[inspect]`, `[adjacent]`, `[similar]`, `[calendar]`. Their plans are in `docs/plans/2026-11-24-shortcode-*.md`.

The other ten had not reached the bar when the fifth plan reached it, so iteration stopped. A second round on 2026-11-26 implemented five of them: `[tabs]`/`[tab]`, `[action]`, `[excerpt]`, `[pivot]` and `[relations]`. Their plans moved to `docs/plans/2026-11-26-shortcode-*.md`, each with a Review section.
